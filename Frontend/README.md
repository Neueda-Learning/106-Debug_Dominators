# Frontend - FasterPay

This module contains the FasterPay frontend application.

## Path

- `Frontend`

## Stack

- React + TypeScript
- Vite
- TanStack Router
- ESLint + Prettier

## Setup

```powershell
Set-Location .\Frontend
npm install
```

## Available Scripts

```powershell
npm run dev
npm run build
npm run preview
npm run lint
npm run format
```

## Frontend Structure

- `src/routes` - route pages
- `src/components` - shared UI and feature components
- `src/lib` - API and utility helpers
- `src/router.tsx` - router setup

## Local Development

Backend CORS defaults include localhost frontend origins. Ensure backend is running while testing API-integrated pages.
